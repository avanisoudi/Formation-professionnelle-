## ⚡ Aperçu du Projet

**SERPENT X** repousse les limites du jeu classique en fusionnant une ambiance *cyberpunk* immersive, un moteur de rendu ultra-fluide sur **HTML5 Canvas**, un mode multijoueur pair-à-pair (**WebRTC**) et une interface entièrement adaptative pour ordinateurs et mobiles.

> *"Un design léché, des effets visuels néons saisissants et une jouabilité instantanée sans aucune installation requise."*

---

## ✨ Caractéristiques Principales

| Fonctionnalité | Description | Technologies / Outils |
| :--- | :--- | :--- |
| 🎨 **Design Cyber-Arcade** | Esthétique néon immersive, typographies futuristes (*Orbitron* / *Share Tech Mono*) et palettes personnalisables. | CSS3 Custom Properties, Google Fonts |
| ⚔️ **Mode Combat P2P** | Affrontements en temps réel entre joueurs sur Wi-Fi ou 4G via un système de connexion sécurisé par code unique. | WebRTC / PeerJS |
| 📱 **Expérience Responsive** | Contrôles adaptés à toutes les plateformes (clavier PC ou D-pad tactile virtuel pour smartphones et tablettes). | Touch API, Native Event Listeners |
| 📊 **Profils & Stats** | Suivi persistant des scores par joueur, des victoires en multijoueur et des records de niveaux atteints. | Browser LocalStorage |
| ⚙️ **Panel Avancé** | Suite de configuration et de modificateurs de gameplay intégrée pour personnaliser l'expérience de jeu. | Vanilla JavaScript DOM API |

## 🕹️ Guide des Commandes

### 🖥️ Bureau (PC / Mac)
* **Direction** : Flèches directionnelles ou touches `W`, `A`, `S`, `D`
* **Pause / Reprise** : Touche `ESPACE`

### 📱 Mobile & Tablette
* **Direction** : D-pad virtuel tactile intégré à l'écran
* **Pause** : Bouton central `⏸`

---

## 🚀 Démarrage Rapide

Le projet est entièrement encapsulé dans un **fichier unique** (`index.html`), garantissant une portabilité totale et un déploiement instantané.

1. **Téléchargez** ou clonez le dépôt.
2. **Ouvrez** le fichier `index.html` directement dans n'importe quel navigateur web moderne (Chrome, Firefox, Safari, Edge).
3. **Jouez !** Aucun serveur local ou gestionnaire de paquets (`npm`, `yarn`) n'est requis.

---

## 🛠️ Stack Technique

* **Moteur Graphique** : HTML5 Canvas (Contexte 2D optimisé).
* **Interface & Style** : CSS3 moderne (Flexbox, Grid, Keyframes, effets de flou `backdrop-filter`).
* **Réseau & Synchro** : PeerJS pour la signalisation et la communication P2P en temps réel.
* **Persistance des Données** : API `localStorage` pour la sauvegarde locale des performances.
